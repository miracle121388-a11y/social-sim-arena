# 真实数据接入与最小采集方案（尚未开展）

当前real_observed事件数量为0。所有30人画像、关系、概率、行为、真值和活动配置均为新生成的synthetic。派生指标标derived并保留input_provenance。模型返回内容以后标model_generated，不能标真实观测。没有读取原项目数据库、个人记录或密钥。

建议最小数据：经审批/同意的多个独立活动，活动层公开通知与发布时间、容量、报名窗口、排队规则；参与者层不可逆研究ID、实际递送/查看的可证实时间、报名尝试、是否成功、取消与到场。只采集研究必需的事前兴趣/可用时间，不默认采集人格全量问卷、聊天内容、实名、电话或完整社交关系。网络传播只在授权情况下记录去标识边及发送/到达证据。实际到达与“阅读/理解/愿意参加”须区分，心理变量无直接证据则缺失。

data/templates仅有空表头和字段schema。src/njusim/data_protocol.py可验证带时区窗口、事前特征时间、observed/censored、重复机会、provenance；默认拒绝real_observed。授权后还需一个将组织方原始日志映射至该schema的专门导入器；当前没有集成自动采集，也没有取得审批。

每行定义风险集/机会：某通知已递送才可能观察view；收到参与信息且窗口未关闭才有join机会；只有成功报名才有attendance风险。未观测=空label，不等于0。右删失不当未发生；仅完成报名者可看到某些反馈会产生选择偏差。首轮fit明确排除missing/censored，尚未实现逆概率加权/联合缺失模型；在真实研究中必须报告缺失机制敏感性，不能把“complete-case”当无偏估计。

切分以独立活动及时间为单位，训练/开发在先，测试在后；S3组合在开发前冻结。分别分析同人新事件、新人新事件，人物画像、检索、提示词例子同样遵守切分。测试的真实结果进入隔离评测库，不能用于运行时调参或填充人物未来记忆。one-step给截至预测点真实历史；free-rollout只给起点和事前已知安排；两者分别评分。

主要预注册指标：阶段NLL/Brier和校准曲线、按人口归一化registered/waiting/attended时间轨迹MAE、约束违反率与错误原因。真实推断采用独立事件/适当群集bootstrap或层级模型，报告事件数与区间；随机seed不是独立事件。少量真实事件时只报告描述结果与区间限制，不许凑样本量。

采集前需确认数据管理员、参与者同意、院校伦理/数据审批、保留期、撤回程序、可公开字段和授权用途。身份对照表由有权限的数据管理员单独保管，公开包使用白名单导出，不含可再识别图。未经新授权不联系学生、不抓取、不上传供应商、不生成真实通知。
