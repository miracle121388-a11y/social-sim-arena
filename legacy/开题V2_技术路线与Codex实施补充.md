# 开题 V2｜技术路线、创新边界与 Codex 实施补充

日期：2026-10-10  
对应提案：**面向未见事件组合的多智能体社会模拟——机制分歧驱动的过程证据选择与校准**  
性质：内部研究设计与实施说明，不与两页提案合并提交。新增方法均为 proposed；没有声称已实现、已取得真实数据、已产生性能提升或已获奖。

## 一、与第一版的关系

本补充基于用户上传的两页提案。保留其校园活动场景、共享行为机制、局部信息限制、意图与执行分离、独立活动划分、下一步预测与自主推演分开、真实数据授权尚未取得等事实和边界。

原稿的技术主线是：少量共享参数，比较仅过程、仅群体轨迹、联合校准。V2 不删除这一实验，而是把它保留为重要基线，增加一个更明确的研究问题：

> 多组行为机制同样解释历史，却对新组合给出不同预测时，应该先获取哪一条过程证据，才能以较少的数据降低组合预测误差？

原稿第五节报告已经完成独立内核、三类场景、微观回放、合成校准流程和 SocioVerse 适配一致性检查。本补充沿用这些**团队报告的工程状态**，没有审计源代码。机制候选集合、查询评分器、预算控制数据接口和新实验尚待实现。

### 研发边界不变

原校园产品只读；原代码、架构、环境、数据库、部署和 Git 状态不变。仅在此前已另建的独立参赛项目扩充方法模块。不要再次新建一套模拟器，也不要为了本次开题修改原项目。已冻结的旧版副本保持不变。

## 二、创新应怎样表述

### 已有研究，不作为我们的原创

- CALM 已包含校准随机选择、网络反馈、可行性约束和回放。依据：Cheng, 2026，arXiv:2609.22252。
- SocioVerse2 已包含纵向社会模拟和可控研究流程。依据：Zhang et al., 2026，arXiv:2609.24911。
- 保留与数据相容的模拟器参数集合、应对非唯一校准，已有 eligibility-set 方法。依据：Bai et al., ICAIF 2022，arXiv:2112.03874。
- 直接按未来预测目标而非全部参数的信息量选择数据，已有 goal-oriented optimal experimental design。依据：Zhong et al., SIAM/ASA Journal on Uncertainty Quantification, 2026，arXiv:2403.18072。
- 大规模人口模拟与数据校准也不是新问题。可扩展比较：Chopra, Large Population Models, arXiv:2507.09901；Zhao et al., macro2mind, arXiv:2610.07062。

### 本项目拟检验的增量

将有限过程观测、共享阶段机制和未见规则组合纳入同一预算受限问题：维护相容机制，测量它们经完整反馈传播后的群体预测分歧，用低开销评分选择真正影响组合预测的证据，并在独立事件上检验数据效率及失效边界。

这是一条**候选方法路线**，不是已确认的首创。下面的协方差公式是有限混合模型下全方差公式的直接推导，不应包装为新的普适定理。若最终只是把标准预测导向设计换成校园数据，没有新的计算优势、可靠性结果或实证发现，不能仅凭新名称声称顶会级算法贡献。

## 三、方法的具体定义

### 3.1 状态与参数

保留现有执行顺序：局部观察 → 行动概率 → 行动尝试 → 社会互动/资源结算 → 状态反馈。

对行为阶段 m，可先使用低参数残差校准：

\[
p_{i,t,m}=\sigma\{\operatorname{logit}(\tilde p_{i,t,m})+b_m+\beta_m^\top f_{i,t,m}\}.
\]

- `tilde p` 为固定版本 Jev、LLM 或统计模型的初始概率；所有概率裁剪常数与后端版本需固定。
- `f` 只含该人物当时可见的信息与可用个体状态，不能含最终真实结果、隐藏全局信息或测试期答案。
- 低维参数在活动之间共享；个人特征进入条件变量，不等于所有人行为相同。
- 该形式是实现起点和校准基线，不是新增算法本身。
- 对互斥动作使用多项分布；对已经报名者才定义取消机会，避免把不适用动作也当成负标签。
- 首版可只校准注意、报名、等待退出三个行为阶段；不同时训练新的基础模型。

### 3.2 相容机制集合

候选 k 包括共享参数 `theta_k`，必要时也包括预先定义的少数机制形式。设置训练期的过程误差与轨迹误差约束：

\[
\mathcal H_D=\{\theta_k: L_{\rm process}(\theta_k)\le\epsilon_p,\;
L_{\rm rollout}(\theta_k)\le\epsilon_r\}.
\]

这首先是**经验相容集合**，不是自动具有覆盖保证的置信集合。阈值、搜索预算和候选筛选均在训练/开发阶段确定。可以采用多起点低维搜索或重要性采样，保留不同的相容区域；不得只将同一个最优点加微小扰动后称为多机制。

一组不同参数只能说明候选类中的行为不确定性，不表示已枚举全部现实机制。应设置候选类之外的数据生成方式进行失配测试。

候选权重 `w_k >= 0, sum w_k = 1` 可由明确定义的观测模型形成，也可作为注明性质的经验权重。未建立合法联合似然时，不把这些权重叫作真实贝叶斯后验。

**统计注意：**若群体人数就是同一批完整个体记录的确定性汇总，它不是额外独立信息。可以作为推演损失或一致性检查，但不能重复相乘似然、虚增样本数。部分过程记录与总体轨迹的依赖也须明确建模或作为复合目标处理，不能默认独立。

### 3.3 组合探针与目标

在接触封存测试活动之前，使用训练期规则词表和预先确定的取值范围构造 `probe_compositions`。探针只提供虚拟情境，不提供真实标签。

探针示例：通知窗口 × 名额限制 × 候补规则 × 同伴传播。已有单机制组合的测试范围应提前登记。训练/开发探针与最终封存组合及具体取值分开记录，避免把对目标测试配置的适配称为完全未见组合泛化。

设 `z_k` 为候选 k 在固定探针集合上的**期望群体轨迹向量**，通过多个随机种子估计。向量可连接报名、候补和到场曲线，按训练期确定的尺度归一化，避免某一人数大或时间步多的维度主导评分。

\[
\bar z=\sum_k w_k z_k,\qquad
D(w)=\sum_k w_k\lVert z_k-\bar z\rVert^2.
\]

`D` 衡量候选机制之间的预测分歧，不是现实误差。全体候选可以共同错误。模拟种子的随机波动另行估计，不把一次抽样的噪声当作机制差异。

### 3.4 证据查询与评分：首版可直接实现

查询 `q` 是训练池中一条**有权限、有来源、可以付出定义成本后获取**的二元过程记录，例如某时间窗是否查看过通知，或某次有效候补机会是否被接受。不是向真实学生无授权地提问，更不是向 LLM 询问后把生成答案当作事实。

设在现有已揭示证据条件下：

\[
p_{kq}=P(Y_q=1\mid\theta_k,D),\qquad \bar p_q=\sum_k w_k p_{kq}.
\]

若揭示标签为 1 或 0，有限混合观测模型下的权重分别为：

\[
w^{(1)}_k=\frac{w_k p_{kq}}{\bar p_q},\qquad
w^{(0)}_k=\frac{w_k(1-p_{kq})}{1-\bar p_q}.
\]

每单位查询成本的预测分歧缩减为：

\[
S(q)=\frac{D(w)-\bar p_qD(w^{(1)})-(1-\bar p_q)D(w^{(0)})}{c(q)}.
\]

对二元查询，令

\[
a_q=\sum_k w_k(p_{kq}-\bar p_q)(z_k-\bar z),
\]

则在上述有限混合模型内：

\[
\boxed{S(q)=\frac{\lVert a_q\rVert^2}{\bar p_q(1-\bar p_q)c(q)}}.
\]

含义：只有当对这条记录的不同预测**关联到组合轨迹的不同预测**时，得分才高。大家对某条记录都输出 0.5，虽然行为熵高，但并不能区分候选；这时得分应为 0。

**适用条件：**`z_k` 是给定候选的目标期望，查询值只通过候选权重改变它；如果查询还直接改变同一人物的目标期状态，或观测与目标共享未纳入候选的潜变量，就不能直接套用该式，需扩充隐状态或显式计算条件推演。缺失历史应边缘化或限制首版查询范围，不得塞入未来真实历史补足。顺序查询的 `p_kq` 必须条件于此前已揭示证据，不能把相关日志视为独立。

`bar p` 为 0 或 1 且所有有权重的候选一致时，查询无区分价值，得分为 0。接近边界时使用数值稳定实现，不以简单扩大分母或极端权重制造虚假收益。

**计算收益的边界：**缓存完整推演和向量化权重更新，可以减少反复重跑模拟器的成本。但标准预测导向方法也可采用这些优化。公平对比必须允许其使用同样缓存，不能故意实现一个低效基线。

### 3.5 两行推导：可检查，不作为新定理

在揭示结果 y 后，记候选加权目标均值为 `mu_y`。全方差分解给出：

\[
D(w)-E_yD(w^{(y)})=\operatorname{Var}_y(\mu_y).
\]

有 `mu_1 - bar z = a_q/bar p_q`，`mu_0 - bar z = -a_q/(1-bar p_q)`，代入即得上式。该恒等式不等于实际数据上的泛化保证，也不证明一个被排除的候选在现实中绝对错误。

### 3.6 更新与完整推演

获得一批证据后更新条件概率与候选权重，必要时用训练数据重新搜索候选。监测有效候选数与搜索失败，避免因粒子枯竭产生虚假确定性。

每条完整推演选定一个候选机制并固定其全程参数，然后对动作随机性采样。不要每一步把各候选概率平均或随机切换机制，这会生成一个未校准的新混合过程并抹掉机制不确定性。

模型版本、候选集合、探针、查询策略、阈值、缓存和随机数标识均保存。测试阶段不补入真实测试过程作为反馈；人物只能根据模拟中产生的可见结果更新状态。

## 四、实验怎样支撑这条方法

### A. 等结果、异机制测试

构造历史总量相近、注意率与参与率不同的生成机制，首先检查该情境是否真的出现组合预测分歧，再比较不同方法。对照还应包含模型类外的等待规则、未知传播延迟、未建模的相关行为等失配。

参数恢复仅在具有已知真值的合成数据上报告。真实数据上报告可观测过程预测和独立事件误差，不宣称恢复了学生真实心理。

### B. 固定预算的证据选择

固定各方法的初始记录、可查询池、成本函数、候选模型、优化和推演预算，比较：

1. 不新增证据的原版联合校准；
2. 随机查询；
3. 行为预测熵最高的查询；
4. 参数信息增益（如 BALD/候选模型信息增益）查询；
5. 标准预测导向设计，使用相同目标向量与缓存；
6. 本项目的阶段过程查询、组合探针与轻量实现。

其中 5 与 6 可能在某些设定下等价：应如实报告相同决策或相同结果，比较开销与适用边界，不声称凭公式改写就提高预测精度。若组合探针、阶段条件化和批量相关处理没有产生独立贡献，需要收敛论文主张。

查询单位须事先定义。若“到场人数”和被查询签到标签来自同一记录，必须处理其依赖和已有信息。没有实际导出费用时，按每条记录等成本只能解释为数据预算实验，不能声称降低了真实采集费用。

### C. 独立事件组合泛化

保持原稿按独立活动和时间划分，报告同人新活动、新人新活动；再按机制组合划分。训练池之外的所有真实标签由评测器隔离。

保留简单统计、未校准 Jev/LLM、仅过程、仅轨迹、原版联合校准等基线。若评估新框架整体，则所有模型信息权限与环境规则一致；原产品仅在隔离副本上运行。

主指标：固定证据预算范围内，事件平均“群体轨迹误差—预算”曲线下面积。建议用容量或有效人群归一化后逐时间步计算 MAE，先在活动内平均再在活动间平均，避免大活动支配结果。

辅指标：Brier、负对数似然、阶段概率校准；区间覆盖与宽度；机制类外失败率；调用成本、推演次数和墙钟时间。区间是模型内预测范围，未经额外论证不能写成具有分布外覆盖保证的置信区间。

数据少时逐事件展示，避免过度统计推断。模拟种子不是独立真实活动。

### D. 缺失与观察机制

未记录查看不等于未查看。对观察窗口结束后的未决结果标为右删失；可选用明确观测模型或限制到完整观察机会。缺失与行为可能相关时，开展观测机制敏感性分析，不假设必然随机缺失。

首版可以只用历史条件完整、机会集合明确的二元记录验证评分。之后再扩展到潜状态过滤和相关批次，不要求在短期内同时完成复杂贝叶斯推断与基础模型训练。

## 五、实施顺序与验收

以下目录/文件名是建议接口，不是已存在路径；Codex 先检查独立参赛项目结构后映射。

### 第一项：候选集合

新增 `calibration/hypothesis_set`，输出候选参数、机制类型、训练误差、权重、版本和采样来源。保留 V1 单点联合校准不覆盖。

验收：存在两组历史拟合近似但组合预测有差异的候选；记录这是构造型合成测试，而非真实发现。

### 第二项：封存数据与取证控制

新增 `evidence/query_pool` 与独立 evaluator。研究算法只能访问已揭示记录及候选查询元数据；隐藏答案存放在受控端，不进入模型提示词、缓存或训练特征。

验收：查询测试活动、超预算、重复查询和无权限字段均被拒绝；真实记录与合成记录分区，来源可追溯。

### 第三项：评分与缓存

新增 `acquisition/composition_score`、`rollout/probe_cache`。先用纯 NumPy 实现二元评分和显式枚举结果的参考实现。

验收：随机权重与概率下，两种公式在数值容差内一致；无关高熵查询得分为零；有候选分歧但目标不变时得分为零；成本加倍时单位成本得分减半；边界概率不产生 NaN。

### 第四项：实验注册

新增配置 `equifinality`、`budgeted_evidence`、`composition_holdout`、`misspecification`。记录初始数据和揭示日志，提前冻结预算网格、主指标、探针和选择规则。

验收：生成三个主图所需数据——相容机制的组合分歧、预算—误差曲线、区间可靠性与模型失配。没有真实授权时图题明确写 synthetic。

### 第五项：论文与参赛同步

两页提案描述新增方法为“拟提出/待实现”；已有进展继续引用真实工程记录。完整研究报告引用实验编号；负结果和等价结果同样保留。

原系统只读、新参赛项目扩展、旧基线冻结这三条不得变更。无需重新设计三维前端，先让方法和证据成立。

## 六、可作为项目交接的状态补丁

- 原项目保护：不变。
- 已完成工程：以第一版提案第 5 节为团队报告依据，等待仓库测试记录进一步核验。
- V1 方法：保留为 passive joint-calibration baseline，不删除、不改写历史结果。
- V2 新方向：机制分歧驱动的过程证据选择与校准，状态 proposed。
- 已完成本次材料：两页优化提案、此技术补充。
- 未完成：新增候选集合、取证评分在真实内核上的实现和实验；真实数据授权；真实行为预测验证；比赛正式提交。
- 下一项任务：Codex 在独立参赛目录建立候选集合与二元评分的最小测试，不改动原校园项目。
- 若方法只等价于已有预测导向设计：收窄创新表述，将可复现评测、实际计算收益和实证发现作为证据，不另造术语替代结果。
