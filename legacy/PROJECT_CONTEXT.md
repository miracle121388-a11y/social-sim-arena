## 本轮实现事实

一个原生内核运行 S1 通知参与、S2 名额候补退出、S3 同伴传播＋冲突＋名额；每场景30个新生成、明确标注 synthetic 的人物。观察只含已递送信息、自己的历史/预算/日程；环境结算隐藏容量、资源和冲突。日志区分意图、尝试、成功、到场；理解变量未观测，未造心理标签。群体统计由日志计算。

两个无 API 的后端、注入式 Jev/LLM 插件、共享 logit/softmax 校准器已实现。局部/宏观/联合约束比较在合成 fixture 上跑通；2个训练事件、1个开发事件、4个测试事件，其中S3只在测试，另有新人事件。固定模型后评估 one-step 与 free-rollout。实际证据见 STATUS.md 和 registry。

官方薄适配仅包装新原生内核。固定 SocioVerse2 提交 `9c3ac774816511c121184ca11f539dc398ba1544`；使用真实 ABC 和 LongitudinalSimulator、独立 DuckDB；完整微日志保存在 sidecar。原系统 B0 尚未全量复现；统一环境原始 Jev/LLM B2 尚未调用。官方 warm-start 和多轮外层回放不支持并显式拒绝。

## 证据边界和数据缺口

当前所有行为结果是 synthetic；没有真实连续过程数据、授权关系网络或真实事件标签。合成软件测试不是现实预测有效性，也不是跨真实事件泛化。模拟随机种子不是独立真实事件样本数。一步预测使用合成生成器的历史；并非真实历史。3个种子的 min–max 只是模拟波动范围，不是人群置信区间。

画像不预设有效；人格消融需真实标签支持。宏观相似不唯一识别机制；模型内反事实不是现实因果效应。L1–L4 问卷不能替代纵向行为。模块化、记忆、概率校准、宏观监督、回放与模型升级都不是自动创新。尚不能提出任何提升幅度或发表、获奖结论。
