## 2. 现有资产：用户描述，尚未由本助手审计

南京大学校园多智能体社会模拟器。自然语言输入事件与观察时间，从约5000个合成人物中选取群体。人物有稳定人格、兴趣、经历和目标，基于自身状态、日程、实际收到的信息及任务内记忆，经 Jev 或 LLM 生成行为概率；环境结算动作、资源与网络传播，并反馈后续决策。三维校园与报告呈现群体变化、个人轨迹和推演依据。

已知不足：事件类型存在部分独立执行路径；人物与关系主要是合成数据；人格对真实行为预测的增益未充分验证；部分宏观结果依赖模型综合判断。

未知：原仓库地址、真实根路径、技术栈细节、可运行程度、Jev具体版本、真实数据的内容与授权、团队最终报名信息及比赛报名是否完成。不能自行补齐。

## 3. 已确认的候选研究主线

可校准、可组合、可验证的社会模拟框架。

核心问题：从真实过程数据校准跨事件共享的行为机制后，能否在独立新事件及未见机制组合中，改善个体行为预测与群体轨迹？

工作标题：From Local Decisions to Collective Outcomes: Calibrated Compositional Social Simulation。它是暂定论文标题，不是已投稿名称。

运行闭环：局部观察—个体决策—社会互动—环境结算—状态反馈。
科研闭环：训练数据—机制校准—开发集选择—版本冻结—独立事件测试。
两者必须分离。测试时人物可以根据模拟经历改变，研究者不能利用真实测试结果实时调参。

## 4. 优先做什么

独立工作区与源项目保护；最小共享机制内核；阶段级概率与资源结算；完整执行日志；简单且有竞争力的基线；过程和轨迹共同约束的校准候选方法；独立事件与组合泛化实验；非侵入式比赛适配。

首批过程：信息接触与参与选择；资源竞争与适应；两者在新事件中的组合。

不优先：原产品重构、更大人口库、更多三维资产、全新基础模型训练、全自动科研平台或重做完整问卷 Benchmark。

## 5. 科研结论边界

- 5000 个合成人物不等于5000名真实受试者。
- 没有已验证的提升幅度、获奖结果或顶会录用保证。
- 模块化、记忆、概率校准、宏观监督、回放本身不是自动成立的原创点。
- 只拟合总量不能唯一识别个体机制；过程可追溯不等于真实因果机制已证实。
- 一步预测与自主推演分开；同人新事件与新人新事件分开。
- 合成 smoke test 只证明软件与假设条件下的机制行为，不证明现实预测有效。
- 缺真实关系网络时不能声称网络准确；缺个体标签时不能声称个体真实性得到验证。
- 单次问卷不能替代真实纵向行为；短期数据不能支持真实长期行为准确性的主张。
- 未经批准，不采集、披露或向外部模型传送可识别学生信息。
