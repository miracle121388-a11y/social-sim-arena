# Standard V3 V0 protocol, fixed before development outcomes

The user authorizes replacing the default benchmark and algorithm, not rewriting
V1/V2 evidence. Their complete tracked release is archived in dist/v2-before-v3.zip;
the original root cache and entry points also have byte-preserving snapshots.
This is a new synthetic diagnostic benchmark. No desired method ranking is an
acceptance test, and no test labels may guide benchmark design or V0 selection.

## Mechanisms and composition
200 mechanisms are the product of two attention-participation products, five
attention levels, five cascade strengths, and four nuisance audit propensities.
Within either product, 25 structurally different predictive mechanisms (100
including nuisance variants) have the same historical intentions. History
enables queueing OR forwarding; only their combination triggers peer cascades.
The nuisance parameter describes an auxiliary audit process, not target dynamics.
This intentional factorization is disclosed rather than sold as a social law.
Validate historical alias-class diameter <.012 and combined candidate diameter
>.18 before evaluating development outcomes. Report the whole pairwise distance
distribution: the diameter criterion does NOT say every pair is >.18 apart.
Probe, dev and test event settings differ; all three still belong to the same
constructed all-components-on family. This is not evidence of real-domain transfer.

## Evidence and costs
32 latent audit episodes each generate four sensor records with reliability .97.
Sensors are independent conditional on the episode; they are dependent given
only the mechanism. Querying repeated records must use the conditional likelihood,
not multiply independent marginal probabilities. MCAR missingness contributes one.
Episodes include attention, cascade, ordinary intention, nuisance-parameter, and
known-p=.5 records. Costs are .5, 1, or 2 budget units. All evidence is obtainable
at source activity 0 in separate pilot cohorts; target labels are never queries.
Full conditions hypothetical episode likelihoods inside each batch; NoBatch uses
the same real posterior but freezes acquisition scores within the batch. Baselines
receive the same conditional observations and batch conditioning, except Random.
Thus correlated records cannot manufacture a benefit through incorrect inference.

## Frozen evaluation
Budgets are monetary/access costs [0,2,4,8,12,16], NOT record counts. Do not exceed
any checkpoint; report actual expenditure and chosen record IDs. All five primary
selectors clone exactly the same calibrated w0 and use the same posterior code.
Reject nonfinite/unnormalized priors and ESS<15 with penalty 999 before any policy.
MAP is an explicitly labelled diagnostic ablation created by the evaluator only
after the full prior passes; its one-point state is not a loophole for methods.

Use activitywise RMSE of fractions; normalized trapezoidal AUC; 12 independent dev
worlds and 24 sealed test worlds. Bootstrap whole worlds 2000 times using the fixed
seed; report paired ablation-minus-Full intervals, each activity and macro values.
No post-hoc significance threshold or test-world selection. Brier is an independent
audit marginal score, never a likelihood that double-counts correlated sensors.

NoSharing uses 800 cached joint hypotheses with independent parameters by activity,
generated by stratified random permutations of the same candidate library. Initial
joint weights are proportional to the product of shared marginal weights. This
necessarily changes the prior dependence and incurs particle approximation; it
does NOT satisfy literal identical joint-prior comparison. Report its actual
marginals and ESS and do not attribute every difference solely to sharing.

V0 has a prespecified calibration width .015, process weight 1, ESS floor 15,
Bayesian likelihood temperature 1, and increasing probe time weights 1 to 2.
No search is authorized in this task. Run the default generator, fast dev, and
development ablations once; preserve failures and negative/indistinguishable
comparisons. The test data remain sealed for a separately authorized final test.
No paper claims of SOTA or universal module effectiveness follow from this setup.
